# DevCard — Beautiful GitHub Profile Cards

Generate beautiful, shareable developer profile cards from any GitHub username. Free, instant, no signup.

**Live Demo:** [devcard-tool.surge.sh](https://devcard-tool.surge.sh/)

## Features

- **Instant cards** — Enter a GitHub username, get a profile card in seconds
- **6 themes** — Dark, Midnight, Purple Gradient, Sunset, Forest, Ocean
- **Real data** — Repos, stars, followers, forks, and top languages via GitHub API
- **High-res PNG** — 2x resolution for crisp display everywhere
- **Copy to clipboard** — One-click copy for quick sharing
- **No signup, no tracking** — Everything runs in your browser

## How It Works

1. Enter any GitHub username
2. Fetches public profile data via GitHub REST API
3. Renders a card on HTML Canvas
4. Download as PNG or copy directly

## Tech

- Pure HTML/CSS/JavaScript — zero dependencies, zero build step
- Canvas API for card rendering (no html2canvas needed)
- GitHub Public REST API (no auth token required)
- Responsive, works on mobile

## Use Cases

- Add to your GitHub profile README
- Share on social media
- Use in presentations or portfolios
- Generate cards for team pages
